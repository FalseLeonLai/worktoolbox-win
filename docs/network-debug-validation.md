## 未进行的硬件验收

尚未连接真实 COM 设备、RS-485 总线或 PLC。串口驱动、USB 转换器、RS-485 收发方向控制及具体 CPU 型号/固件的兼容性需要实机确认。S7 为经典绝对地址子集；单次最多 200 字节且受协商 PDU 限制，不支持 S7CommPlus/优化 DB/自动分块。RTU 不宣称具备硬件级 t1.5 逐字节时序测量能力。

测试只连接本机模拟端，没有执行真实 PLC 写入或修改 CPU 配置。临时验证脚本与分析材料留在被 Git 忽略的 `target/`，不进入发布程序。
