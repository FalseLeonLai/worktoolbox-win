# 网络与串口调试

从左侧菜单进入「网络与串口调试」。选择模式、填写连接参数，然后连接。程序一次持有一个调试连接；切换到工具箱的其他页面仍保持通信。连接参数在连接期间锁定，点击断开后等待后台操作退出即可修改。

本页为纯 Rust 实现，参考 HslCommunication Demo 的调试工作流。没有移植闭源核心，也不携带 HSL、.NET 或 Snap7 运行库。首版覆盖用户选定的协议，后续可分批增加协议。

## 网络与串口

| 模式 | 连接设置及行为 |
| --- | --- |
| TCP 客户端 | 目标 IP 和端口；按字节流收发，单条接收记录不代表完整业务报文 |
| TCP 服务端 | 本地 IP 和监听端口；一次调试一个客户端；端口 0 自动分配，状态栏显示实际端口 |
| UDP | 本地 IP/端口与目标 IP/端口；保留数据报边界，接收记录显示发送方 |
| 串口 | 刷新并选择端口或手填 COM 名称；波特率、5～8 数据位、1/2 停止位、无/奇/偶校验、无/软件/硬件流控 |

网络地址接受 IPv4/IPv6 字面值。IPv6 的本地绑定也要使用对应地址，例如 `::`。超时范围 100～5000 ms；周期最短 100 ms。TCP 服务端可绑定 `127.0.0.1` 进行本机测试，或绑定指定网卡 IP 接受设备连接。

原始发送支持连续或空白分隔的 HEX（例如 `01 03 00 00 00 02`）、UTF-8 文本，并可追加 CR、LF、CRLF。每次最多 65507 字节。周期发送使用启动时的报文和间隔；修改内容后先停止周期，再启动。

日志显示相对工具启动的时间、方向和内容，支持 HEX/文本切换、暂停显示、清空和复制。界面最多保留 1000 条且载荷与说明合计不超过 2 MiB，每条预览最多 512 字节；复制包含保留记录的完整内容。暂停时仍消费后台数据并保留最新记录，取消暂停后显示。超限丢弃会计数提示。原始 TCP/串口记录按读取批次显示，文本预览对无效或被批次切开的 UTF-8 使用替代字符；精确字节请查看 HEX。

## Modbus TCP / RTU

此页作为客户端/主站。可读取线圈（FC01）、离散输入（FC02）、保持寄存器（FC03）、输入寄存器（FC04）；写入仅支持线圈和保持寄存器。单项自动使用 FC05/06，多项自动使用 FC0F/10。

- **地址从 0 开始**，不是 `40001` 形式的资料编号。例如手册将第一个保持寄存器标作 `40001` 时，通常选择保持寄存器、填写地址 `0`；以设备手册的映射为准。
- 读取数量始终是**位数或 16 位寄存器数**。例如读取一个 F32 需要 2 个寄存器，不是数量 1。
- 数值写入检查输入载荷与填写的数量一致；数值之间用空格或逗号分隔。HEX/UTF-8 写寄存器时必须是偶数字节，程序不会隐式补零。
- 支持 U8/I16/U16/I32/U32/F32、HEX 和 UTF-8。字节序可选 ABCD、BADC、CDAB、DCBA；16 位值中 ABCD/CDAB 为大端，BADC/DCBA 为小端。
- RTU 站号为 1～247，不提供广播写入；TCP 站号允许 0～255（网关常用站号以设备配置为准）。
- 读取最多 2000 位或 125 寄存器，写入最多 1968 位或 123 寄存器。地址加数量不得超出 65536。

TCP 校验 MBAP 长度、事务号、站号、功能码和返回数量。RTU 校验站号、功能码、长度、CRC 和写回值，发送前排空残留并等待总线静默。Windows/USB 串口无法提供精确的逐字节到达时间，**本版不作为 t1.5 帧内间隔测量工具**。设备异常、超时或报文失配都会停止周期并关闭连接；重新连接后再操作，避免迟到响应串入后续事务。

## Siemens 经典 S7

连接使用 IP、端口（通常 102）、Rack、Slot 和连接类型（PG/OP/S7）。具体参数必须与目标 CPU 配置一致。仅支持经典 S7 绝对地址通信，不包含 S7CommPlus、符号寻址、CPU 启停或程序下载。

| PLC 地址示例 | 页面参数 |
| --- | --- |
| DB1.DBW0 | DB 区、DB 号 1、字节偏移 0、读取 2 字节、U16 |
| DB1.DBD4（REAL） | DB 区、DB 号 1、字节偏移 4、读取 4 字节、F32 |
| M10.2 | M 区、字节偏移 10、位模式、位号 2 |
| I0.0 / Q0.0 | I/Q 区、字节偏移 0、位模式、位号 0 |

S7 原生数值使用大端，切换到 S7 模式默认选择 ABCD；也可按自定义字节数组的格式调整字节序，编码和结果解释均使用当前选择。字节偏移范围 0～2097151，位号 0～7。每次最多 200 字节，并受设备协商 PDU 减去报文开销的上限限制；不自动分块。单个位使用 S7 位操作，不会通过读改写整个字节覆盖邻位。读写长度均为字节数，写入载荷必须与填写的长度一致。

对于需要 PUT/GET 访问许可、非优化 DB 的 CPU，请先按厂家文档配置。本程序不会改变 CPU 配置；对输入区等不可写地址，设备可能拒绝写入。协议能力和权限仍由具体型号/固件决定。

S7 日志和 TX/RX 计数反映读写的**有效载荷**，不包含握手或完整网络报文；Modbus 日志显示完整协议帧。工业协议仅允许周期读取，写入由按钮明确触发，不自动重试。

## 验证与使用边界

自动化验证包括数值/字节序、标准 Modbus 帧与异常、RTU 注入字节流、TCP/UDP 本机回环、服务端断开重连、周期停止、S7 模拟端握手/分段/PDU/位操作/超时和日志容量。真实 COM 设备和 PLC 尚未接入验收；这些模拟结果不代表已覆盖所有设备型号。

配置和通信记录只保留在当前运行期。关闭程序后不会保存连接参数或业务报文；原有启动诊断日志仍按工具箱既有机制记录。
