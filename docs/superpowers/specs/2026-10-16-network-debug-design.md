# 网络与串口调试首版设计

用户已选择纯 Rust 单文件、分批实现协议；首版包含 TCP 客户端/服务端、UDP、串口、Modbus TCP/RTU 和 Siemens 经典 S7。

## 用户行为

- 左侧新增「网络与串口调试」，保留原有「通信参考」，沿用深浅主题、卡片和等宽报文显示。
- 页面按「连接设置 → 操作 → 通信记录」排列，最小 900×600 窗口可滚动操作。
- 一次打开一个连接；TCP 服务端一次调试一个客户端。连接时锁定连接参数；切换工具页保持连接；断开停止周期任务并释放端口。
- 原始模式支持 HEX / UTF-8 文本发送、追加 CR/LF/CRLF、手动或周期发送、接收 HEX / 文本、时间戳、TX/RX 字节数、暂停显示、清空和复制记录。
- 串口支持端口刷新/手填、波特率、数据位、停止位、奇偶校验、流控。
- Modbus 为主站/客户端，提供线圈、离散输入、保持寄存器、输入寄存器读取，线圈/保持寄存器写入，自动选择单/多写功能码；明确使用从 0 开始的协议地址，支持站号、周期读取、数值及字节序解释。
- S7 支持 DB/M/I/Q 字节和单个位读写。使用区域、DB 号、字节偏移、位号表单，连接参数为 IP、端口、Rack/Slot、连接类型。首版不包含 S7CommPlus、符号寻址、CPU 启停、程序下载。
- 两类工业协议共用单次读、周期读、显式写入、结果显示与错误信息。写入不自动重试、不默认周期写入。

## 实现边界

- Rust std::net + serialport；不打包或加载 HSL/.NET/Snap7 DLL。
- HSL Demo、XML 和分析交付包仅提供功能参考；协议按公开规范实现，不移植闭源核心代码。
- 同步 I/O 由后台线程持有，GUI 不直接连接或等待设备；每次操作有超时，UI 每帧在路由前消费事件。
- 接收与界面记录都有容量上限；暂停显示仍消费后台数据；日志超限保留最新记录并提示丢弃数。
- TCP 按流处理；UDP 保留数据报边界；Modbus 校验帧长度、事务号/站号/功能码/CRC；S7 按 TPKT 长度收完整报文并匹配 PDU reference。
- 连接参数只接受 IP 地址，不在不可取消的系统 DNS 查询中阻塞退出。
- 超时或协议帧失配后关闭工业协议连接，要求显式重连；错误包含操作和原因。
- 本版配置保留在运行期，不新增磁盘配置系统；单文件程序继续离线启动。

## 验收

- 原 21 项测试保持通过。
- HEX、UTF-8、数值转换、字节序、越界输入和日志容量的单元测试。
- TCP/UDP 回环收发；TCP 服务端接入/退出；串口通过可注入字节流验证核心逻辑，真实 COM 测试单独记录。
- Modbus 标准帧、异常帧、CRC/事务号错误、分段响应、数量限制、单/多写回执测试。
- S7 握手、TPKT 分段、PDU reference、设备错误、DB/M/I/Q 区域编码、单个位写入与超时测试。
- Windows release 构建；新页深浅主题、最小窗口、切页保持连接与断开释放资源检查。
- 没有真实 PLC/串口设备时明确标记硬件验收尚未进行，不把回环通过等同于实机兼容。
